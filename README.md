# n8n-sprint2-issue-triage
https://github.com/donoftime2018/n8n-sprint2-issue-triage 
Week 6 public test repository for an n8n GitHub Issue Triage workflow 

The week 6 Sprint 2 n8n GitHub Ledger Issues workflow was designed to record the necessary information about any new issues made to this repository. This information includes, but is not limited to, the issue title and url, the type of issue based on the title, and the reporter of the issue. The issue logged to either the github_issue_ledger or github_issue_route_log.
